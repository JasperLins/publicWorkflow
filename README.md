# AI 项目开发团队前期讨论工作流框架

> **把一个不成熟的想法,变成一套可直接落地开发的企业级项目文档。**
> 模拟互联网技术公司立项前的全过程:头脑风暴 → 创新 → 可行性 → 市场供需与竞品 → 需求/功能整理 → 技术栈与第三方成本 → UI/UX 与高保真原型 → AI 开发周期与 token 预估 → 利润计算与甲方报价。
> 本框架是**公用框架,不限于任何一个项目**:仓库即框架,克隆即用,项目与框架完全分离。

## 核心特性
1. **框架/项目分离**:框架文件只读复用,每个项目独立位于 `projects/<项目名>/`(docs+memory+UI),一条命令初始化,互不污染。
2. **9 个专业子代理角色**(harness 编排模式):项目经理、市场分析师、架构师、高级全栈工程师、UX 设计师、高级 UI 设计师、AI 开发高级工程师、AI 高级提示词优化员、成本利润商务顾问——由主代理按**委派四要素**(目标/输出格式/输入/边界与完成标准)统一启动、协调、裁决。
3. **13 个专业技能(skills)**:标准 SKILL.md 提示词库,description 英文主句+中文副句(触发更稳),多数技能内置**投入缩放档**(轻量/标准/深度),报价类技能挂 references/ 行情基准表。
4. **记忆模块(每项目独立)**:项目画像 + 决策与假设双账本 + 产出索引(唯一进度源)+ 待议池,分块限额、双触发蒸馏、关键词检索。
5. **单轮批量提问**:阶段末一次性编号+选项+推荐项+回退项,回复"1A 2B"即可,选择自动入记忆。
6. **文档模板驱动**:13 个标准模板,统一「文档头契约」(关键结论/假设/可引用承诺/未决问题)供下游按需注入,数字结论必须带计算过程。
7. **门禁预检 + 输入/输出闸**:门禁阶段先机器自检再问用户;阶段开始查上游完备性,落盘前查结构完整性,支持断点续跑。

## 目录结构
```text
publicWorkflow/               # 仓库根 = 框架(只读复用)
├── AGENTS.md                 # ⭐ 总控 v1.5:注册表、工作流、协作协议、批量提问协议、规范
├── README.md
├── roles/                    # 9 个子代理角色定义 + 委派四要素启动模板
├── skills/                   # 13 个专业技能(含 delivery-packager 与 references/ 行情表)
├── templates/                # 13 个产出文档模板(含客户确认单与 AI 移交包)
├── workflow/                 # 8 阶段执行指南(门禁预检/输入输出闸/回填循环)
├── memory/                   # 记忆模块模板(项目初始化时复制)
├── scripts/init-project.sh   # 项目初始化脚本
├── projects/                 # ⭐ 你的项目们(与框架分离,每项目独立 docs/memory/UI)
│   └── fridge-keeper/        #   示例:端到端实测项目(已完成 0–7 + v1.4 回溯)
├── _research/                # 框架优化调研报告(参考)
└── _test/                    # 冒烟测试沙盒(参考,含 UI 原型样例)
```

## 快速开始(每次开发新项目)
```bash
# 1. 克隆框架
git clone git@github.com:JasperLins/publicWorkflow.git && cd publicWorkflow

# 2. 初始化项目(框架/项目分离)
./scripts/init-project.sh my-project     # 在 projects/my-project/ 建骨架
```
```text
# 3. 启动工作流:在仓库根打开 ZCode(或其他支持 AGENTS.md 的 AI 代理),说:
「读 AGENTS.md,按工作流启动项目 my-project,想法是:{一句话}」
```
主代理会在门禁阶段(2/3/5/7)先过预检,再一次给出编号问题清单,直接回复「1A 2B 3C」;任一题可选 D 回退重做。项目全部产出都在 `projects/my-project/` 下:
```text
docs/01-brainstorm/   头脑风暴与方向结论(创意全景/方向打分)
docs/02-market/       市场可行性 + 竞品分析
docs/03-requirements/ 需求文档 + 功能清单(含工时与回填校准)
docs/04-tech/         技术栈 + 第三方服务成本
docs/05-uiux/         UX 流程 + UI 规范
docs/06-ai-plan/      AI 开发计划(token 三档预估)
docs/07-business/     成本利润表 + 甲方报价单
UI/                   高保真静态原型(可直接交给 AI 开发复现)
```
续跑/中断恢复:再次打开会话说「读 AGENTS.md,恢复项目 my-project」,进度从 `projects/my-project/memory/outputs-index.md` 自动续跑。

## 接入 ZCode(可选)
`skills/` 下每个目录即为标准 SKILL.md 格式,可注册为工作区技能以便 `/skill-name` 直接调用;不注册也可用——主代理按 `AGENTS.md` 注册表读取 SKILL.md 注入子代理(默认方式,零配置)。

## 如何进化本框架
- **新增角色**:`roles/` 加文件(沿用统一结构)→ `AGENTS.md` 注册表登记。
- **新增/优化技能**:`skills/<skill>/SKILL.md`(改前备份 `skills/_archive/`,frontmatter 记 version/updated,文尾 CHANGELOG);由提示词优化员在阶段 8 复盘中按「回滚率/修订要点数」数据驱动地执行。
- **调整节奏**:默认门禁 2/3/5/7;项目较小可在 `AGENTS.md` 第四节收缩为 3、7 两阶段。
