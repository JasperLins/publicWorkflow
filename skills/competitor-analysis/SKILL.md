# Skill: competitor-analysis — 竞品分析

> v1.1 变更:description 规范化;新增投入缩放档。

## 输入依赖
- `memory/project-profile.md` + `docs/01-brainstorm/ideas.md`(推荐方向;缺失即阻塞)

## 执行流程
1. **竞品识别**:直接竞品(同需求同方案)≥2 个、间接竞品(同需求不同方案)≥1 个;说明检索方式与时间范围。
2. **功能矩阵**:关键能力项(来自头脑风暴方向 + 竞品共有功能),按 ✅/⚠️/❌/❓ 四态打分(❓=未查到证据,不臆断),标注我方规划;列数按实际竞品数扩展。
3. **定价与商业模式**:每竞品定价档位、收费模式(订阅/买断/抽成/免费+广告)。
4. **优劣势与口碑**:每竞品 2 条核心优势、2 条核心短板(有公开评价时引用来源)。
5. **差异化机会**:≤3 条「竞品没做好、我们有机会」的切入点,各附防守性评估。
6. **问题收集**:对标策略(跟随/差异化/错位)等,批量提问格式。

## 产出要求
- 路径:`docs/02-market/competitor-analysis.md`,模板 `templates/competitor-analysis-report.md`,含文档头契约节。
- 矩阵「我方」列基于头脑风暴推荐方向,不虚构未决策功能。

## 投入缩放
- **轻量**(新赛道/竞品少):3 个竞品、10 个功能项、桌面信息。
- **标准**:3–5 个竞品、10–15 个功能项、定价表完整。
- **深度**(红海市场/定价敏感):5–8 个竞品 + 用户口碑来源引用 + 定价历史变化。

## 质量自检清单
- [ ] 竞品 ≥3 个且分直接/间接
- [ ] 功能矩阵 ≥10 项、含我方列
- [ ] 每个竞品有定价信息(或注明查不到)
- [ ] 差异化机会 ≤3 条且各附防守性评估
