# Skill: quotation-calculator — 成本·利润·报价

## 目标
把工时、第三方费用、token 费用汇总为总成本,计算利润并生成可直接发给甲方的报价单。

## 执行流程
1. **成本归集**(逐项列来源文档):
   - 人力成本 = Σ(功能清单各角色人日 × 对应人日单价),AI 开发项目按人机分工折算。
   - 第三方服务 = `third-party-services.md` 预估月费 × 项目周期月数(计入开发期)。
   - AI 开发费用 = `ai-dev-plan.md` 中性档 token 费用。
   - 其他:UI 资源、测试设备、缓冲金(5–10%)。
2. **利润计算**:目标利润率给三档(保守 20% / 标准 35% / 进取 50%,可按项目调整),列出每档「总成本 → 报价 = 成本 ×(1+利润率)」;注明税费口径(含税/不含税、增值税率假设)。
3. **报价单**:两种口径并列——①按模块包干(引用功能清单模块)②按人天计费;附付款里程碑建议(如 30% 预付-40% 验收-30% 尾款)与交付物清单(对应 docs/ 各文档 + 可运行系统 + 源码)。
4. **敏感性分析**:范围 ±20%、周期延误 2 周、token 超用 50% 三种情景下的利润变化。
5. **竞品锚点**:引用竞品定价,判断报价的市场位置。

## 产出要求
- 路径:`docs/07-business/cost-profit.md`(成本利润表)与 `docs/07-business/quotation.md`(甲方报价单),均用模板 `templates/quotation.md`。
- 所有金额含币种、含税口径、计算式。

## 补充规则(AI 提效项目)
- **双基线分离**:成本基线用 AI 实际投入(人力×单价+token+第三方),定价基线可参照市场公允价;利润公式与报价以**成本基线**计,公允价差作为竞争力分析,不得混入成本表。
- **甲方版零注释**:quotation.md 不得含任何 HTML 注释/编辑注/内部备注(会以裸文本暴露);内部备忘只写 cost-profit.md 与 questions 文件。
- **年费服务折算**:年费制服务(如开发者账号 ¥688/年)按「周期天数 ÷ 365 × 年费」折入开发期成本。
- **延误敏感性换算(AI 执行口径)**:延误成本 = 人力维持率(建议假设 30%)× 延误人日 × 单价;须写明该假设。
