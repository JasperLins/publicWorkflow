## 定价方法(按序执行)

### ① 品类竞争档定价(主定价)
- 按品类从基准表「AI 竞争档」取区间,乘规模系数(模板级 ×0.7 / 标准 ×1.0 / 复杂 ×1.5–2.0)。
- 委托方给的成交锚点**永远优先**于表值(如:完整 AI 加持工具 App ≈ ¥4,000)。
- AI 能力默认**不单独加价**(已是 AI 时代标配竞争力);仅自训练模型/高用量 API 成本显著时另行评估。

### ② 范围-难度校验(超档处置)
- 需求难度/规模明显超出竞争档承载(如多端、硬件、实时协同):要么在竞争档上有限上浮(封顶 ×2,且不超过传统行情下限),要么**显式裁剪范围并经客户确认**——禁止靠暗降质量消化。

### ③ 现金成本红线(口径改变)
- 现金成本 = 第三方开发期费用 + 内容采购 + token(包月口径 ¥0)。**人日是机会成本参考,不计入红线**。
- 报价 ≥ 现金成本 × 1.2(通常约束极弱,如实呈现「现金成本极低,定价由竞争决定」);委托方若声明要核算自身人力,再切回人日口径。

### 报价三档(竞争定位)
- **抢单档**(竞争档下限)/ **标准档**(竞争档中位,通常推荐)/ **上限档**(≤传统行情下限,客户预算充足或竞争少时用)。
- 定价策略最终由委托方在批量提问中拍板;利润额 = 报价 − 现金成本(如实呈现;人日时间投入单列为参考信息)。

## 质量红线(与价格完全解耦,强制)
1. 功能范围与验收标准一经确认,**不因低价缩水**;低价的代价只能是显式裁剪范围(经客户确认)或接受更薄利润。
2. DoD 不降级:构建通过/自测用例/与 UI 原型一致性、NFR 门槛照常执行。
3. 报价单与客户确认单中明示交付质量承诺(验收标准引用),让「低价高质」成为竞争力而非风险。

## 执行流程
1. 按①得竞争档区间 → 按②校验超档 → 按③核对现金红线 → 出三档。
2. 生成 `docs/07-business/cost-profit.md`(内部版:现金成本 + 人日时间参考 + 三档推导 + 利润额)。
3. 生成 `docs/07-business/quotation.md`(甲方版:零内部数字/零注释;分模块包干 + 竞争定位一句;质量承诺条款;人天口径仅甲方要求时并列且用市场计费价)。
4. 敏感性:范围 ±20%、周期延误 2 周、运营期费用归属变更。

## 补充规则
- 甲方版零注释;年费制服务按「周期天数÷365×年费」折入;运营期按量费用归甲方。
- 传统行情区间只用于「上限档」与竞争力对比叙述,不得作为主定价依据。

## 质量自检清单
- [ ] 定价来自「AI 竞争档」或委托方锚点(写明来源),未使用传统行情作主依据
- [ ] 三档 + 推荐理由 + 利润额如实;人日仅作时间参考呈现
- [ ] 质量红线条款已写入报价单/确认单
- [ ] 现金红线核对完成;token 包月 ¥0(或注明按量声明)
- [ ] 报价单可直接发甲方(无内部数字、零注释)
- [ ] 敏感性三情景齐全
