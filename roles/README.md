# roles/ — 子代理角色库

每个角色一个文件:身份、职责、输入(订阅清单)、输出、协作接口、工作纪律。主代理(项目经理)按 `AGENTS.md` 第二节注册表启动它们。

## 统一启动指令模板(委派四要素版)

启动任何子代理时,用以下模板组装提示词(替换 `<>` 占位符)。**注入的固定材料 ≤3 份**(角色文件 + 项目画像 + 任务描述),其余一律路径引用或文档头注入。

```text
你是「<角色名>」。以下是你的角色定义,严格遵守:

--- 角色定义 ---
<roles/<角色>.md 全文>

--- 项目画像(memory/project-profile.md 全文)---

--- 本次任务(委派四要素)---
① 目标:<具体任务描述;请执行 skill:skills/<skill>/SKILL.md(先读取全文)>
② 输出格式:<产出路径 + 模板/SKILL 结构>;回传:结论摘要≤300字 + 文件路径 + 待决策问题(每题含选项与推荐项)+ 本次工作假设清单(编号待登记)
③ 输入:<仅按角色文件「输入」节列出的文档;上游文档优先给「文档头契约」节,全文按需自读>
④ 边界与完成标准:<明确不做什么/排除项> ;完成标准 = <引用 workflow/README.md 该阶段完成标准>
   投入档位:<轻量/标准/深度>(由主代理按阶段 1 结论指定,对应 SKILL「投入缩放」节)

--- 输出要求(强制)---
完成后只回传:① 结论摘要 ② 产出文件路径 ③ 待决策问题列表 ④ 工作假设清单。
不要回传文档全文,不要与用户对话。
```

## 新增角色

把新角色文件放入本目录(沿用统一结构:身份/职责/输入/输出/协作接口/纪律),并在 `AGENTS.md` 角色注册表登记一行,即完成注册。
