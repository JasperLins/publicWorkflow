# 项目画像(Project Profile)

> 状态:已确认(端到端测试数据,沙盒 _test2/)
> 最近更新:2026-08-17

| 要素 | 内容(上限) |
|---|---|
| 一句话概述 | 「冰箱食材管家」iOS App:拍照/扫码录入食材,自动跟踪保质期并临期提醒,基于现存食材推荐菜谱,减少家庭食物浪费 |
| 目标用户 | 25–40 岁城市家庭买菜主力,双职工家庭为主;次要对精打细算敏感的独居青年 |
| 核心价值 | 录入 10 秒、不再因遗忘导致食材过期——帮家庭省下每年数百至数千元的食物浪费 |
| 本期做 | iOS MVP:拍照 AI 识别录入、保质期管理、临期本地推送、基于现存食材的菜谱推荐 |
| 本期不做 | Android、Web 端、生鲜电商对接、多人共享冰箱、社区功能 |
| 关键假设 | 用户愿为「省事+省钱」持续使用并订阅(中);图像识别准确率 ≥85% 可接受(中);订阅制变现可行(低-中) |

## 决策摘要(仅收录改变「范围边界/目标用户/商业模式」的决策)
- D-001:首期仅 iOS,不做 Android/Web(2026-08-17)
- D-002:方向 A「AI 识别+临期提醒+菜谱推荐」确认为 MVP(2026-08-17)
- D-003:MVP 免费,高级识别额度与菜谱库走订阅(2026-08-17)
