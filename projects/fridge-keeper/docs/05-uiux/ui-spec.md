## 6. UI 风格定义

- **设计关键词**(5 个,呼应「高效 / 清爽 / 工具感」与 D-004 差异化「整拍 10 秒录入 + 闭环」):
  1. **新鲜**——绿色系主色 + 高饱和食材缩略图,打开就联想到冰箱里的食材;
  2. **高效**——关键路径(快门→核对→入库)永远一根绿色主轴,主按钮全局唯一;
  3. **清爽**——大面积留白 + 单层卡片,无花纹无重阴影,信息密度克制;
  4. **安心**——临期三档徽章色语义恒定(红/琥珀/绿),提醒而非恐吓;
  5. **工具感**——iOS 原生导航/弹层/开关形态,零学习成本,像系统自带功能。
- **参考风格**:iOS 17 原生设置/提醒事项的分组列表;Fresh-fitness 类绿色轻食 App 的卡片与徽章语言。

### 7.2 字体

- 字体族:`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Helvetica Neue", sans-serif`(iOS 原生栈,零加载成本)。
- 字号层级(= A-032 定档,全局最小 12px):

| 档 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| 大标题 | 28/34 px | Bold | 页面首屏大标题(库存/吃啥/设置/速览/Onboarding) |
| 页标题 | 20/26 px | Semibold | 导航栏标题、弹层标题 |
| 卡片标题 | 16/22 px | Medium | 食材名、菜谱名、表单标签 |
| 正文 | 15/22 px | Regular | 说明文案、列表次要信息、按钮文字(主按钮用 16 Semibold) |
| 辅助 | 12/16 px | Regular | 徽章、标签、TabBar 标签、脚注 |

### 7.3 圆角 / 间距 / 阴影

- 圆角:卡片 16px(`rounded-2xl`)/ 按钮与输入框 12px(`rounded-xl`)/ chips 与徽章全圆(`rounded-full`)/ 半屏弹层顶部 20px / 食材缩略图 12px / 设备壳(index 专属)54px 外、44px 内。
- 间距:基准 4px;页面左右边距 16px;卡片内边距 16px(紧凑 12px);列表项间距 12px;模块区块间距 24px;标题与首行内容 8px。
- 阴影:
  - 卡片 `shadow-card`:`0 1px 2px rgba(31,42,36,.05), 0 6px 16px rgba(31,42,36,.06)`;
  - 悬浮(TabBar/中央快门/半屏弹层)`shadow-float`:`0 8px 24px rgba(31,42,36,.16)`;
  - 内嵌元素(缩略图/徽章)不用阴影,靠色块区分。

### 7.4 组件风格

- **按钮**:主按钮 = `#15803D` 实底、白字 16px Semibold、高 48px、圆角 12px、按压 `#14532D` + `scale-95`;次按钮 = `#DCFCE7` 底 `#15803D` 字;禁用 = `#E6EBE6` 底 `#B9C2BB` 字(原型中并列演示默认/按压/禁用实例);文字按钮 = `#15803D` 纯文字;危险文字按钮 = `#DC2626` 纯文字。触控热区一律 ≥44px。
- **卡片**:白底、圆角 16、内边距 16、`shadow-card`;卡片内多行信息用 12px 间距。
- **列表行**:缩略图 44×44(见下)左,名称 16 Medium + 数量/单位 15 Regular 两行,右侧天数徽章 + `fa-chevron-right` 12px;行高 ≥56px;左滑快捷「标记已用/删除」不做静态演示(交互原则见 ux-flows 5.2)。
- **食材缩略图**:44×44 圆角 12 的**浅色系 CSS 渐变 + 白色 FA 图标组合**(如番茄 `#FF8A80→#E53935` + `fa-apple-whole`)。**设计选择声明:非占位符**——录入场景中缩略图本就承担「识别结果类目」语义,图标化比错误实拍图更诚实;菜谱封面等大图用 Unsplash 实拍直链。
- **表单**:输入框高 44px、圆角 12、白底描边 `#E6EBE6`、聚焦描边 `#15803D`;数量步进器 = `fa-minus/fa-plus` 圆形按钮 + 中间数值 16 Medium;单位切换用 pill 组。
- **chips(筛选/分类)**:高 32px 全圆,未选 = 白底描边 `#E6EBE6` 字 `#44514A`,选中 = `#DCFCE7` 底 `#15803D` 字 Medium。
- **空态**:居中 48px 图标(浅绿渐变圆底)+ 16px 标题 + 15px 说明 + 主/次按钮;禁止灰块。
- **Toast**:深底 `rgba(31,42,36,.92)`、白字 15px、圆角 12、水平居中悬浮于 TabBar 上方,1.5 秒自动消失(原型以静态实例并排演示)。
- **半屏弹层**(D-027 S09 沿用):顶部圆角 20、白色底、顶部把手 36×5 `#E6EBE6`、`shadow-float`;拦截类弹层主出路按钮永远在上(免费手动出路)。
- **TabBar**(D-026):高 60px + Home Indicator 区;白底 95% + 毛玻璃 + 顶部 1px 边线;图标 20px + 标签 12px,激活 `#15803D`/未激活 `#9AA69E`;**中央快门 56px 圆形凸起**(上凸 20px,`#15803D` 底、3px 白描边、`shadow-float`、白相机图标);S11 起 5 位变体(速览插第 3 位,快门居中)。
- **iOS 状态栏**:高 54px,时间 9:41 左,信号/Wi-Fi/电量右,含灵动岛黑色胶囊(120×34);深色屏(拍照/订阅氛围)用白字版本。
- **图标映射**(ux-flows SF Symbols → FA6 免费版,已逐一对 CDN CSS 校验存在性):`refrigerator→fa-box-archive`(FA6 免费版无冰箱图标,取「箱体存储」语义,每屏注释标注)、`fork.knife→fa-utensils`、`gearshape→fa-gear`、`square.grid.2x2→fa-table-cells-large`、`checkmark.seal→fa-circle-check`、`arrow.clockwise→fa-rotate-right`、`photo→fa-image`、`lock.shield→fa-shield-halved`、`magnifyingglass→fa-magnifying-glass`、`bell→fa-bell`、`cloud→fa-cloud`、`bolt→fa-bolt`、`eye→fa-eye`、`crown→fa-crown`、`calendar→fa-calendar`、`trash→fa-trash`、`chevron→fa-chevron-left/right`。
