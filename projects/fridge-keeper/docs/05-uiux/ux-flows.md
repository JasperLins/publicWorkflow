## 4. 关键任务流程(mermaid,含正常 + 异常路径)

### F0 注册登录说明(设计裁剪)

**无注册登录流程**——依据 D-015(无账号纯本地 + iCloud 备份):首次启动直接进 Onboarding(P1,首发前直接落库存首页 S02 空态引导);设置页提供 iCloud 备份开关。

### F1 整拍录入(核心闭环第 1 环,覆盖识别失败 / 无网络 / 额度用尽 N=30 / 权限拒绝)

```mermaid
flowchart TD
    A[点击 TabBar 中央拍照按钮] --> B{相机权限已授权?}
    B -- 否 --> B1[S04 权限拒绝态·引导去系统设置]
    B1 --> M[S06 手动录入页·免费无限]
    B -- 是 --> C{本月识别次数小于 30?}
    C -- 否·额度用尽 --> Q[S09 额度用尽引导]
    Q --> Q1[主出路·手动录入] --> M
    Q --> Q2[次出路·了解订阅 S12·P1]
    C -- 是 --> D[S04 取景拍照或相册选图]
    D --> E{网络可用?}
    E -- 无网络 --> E1[S04 离线提示·本地功能不受影响] --> M
    E -- 可用 --> F[上传识别·加载态 ≤3 秒]
    F -- 成功 --> G[S05 识别结果确认页]
    F -- 超时或失败 --> F1[失败提示·重试或转手动] --> M
    G --> H[逐项核对·数量单位保质期增删]
    H --> H1{有遗漏食材?}
    H1 -- 有 --> H2[S06 补录后返回 S05]
    H1 -- 无 --> I[确认入库·快门起 ≤10 秒]
    I --> J[成功 Toast 1.5 秒·返回 S02]
```

### F2 临期处理 + 做菜闭环(第 3–4 环,覆盖通知被拒 / 缺料边界)

```mermaid
flowchart TD
    ENG[临期引擎·3天 / 1天 / 当天] --> PUSH[本地推送·默认 09:00 可改·免联网]
    PUSH -- 点击通知 --> L[S02 库存首页·临期筛选落地]
    PUSH -- 通知权限被拒 --> BAN[S02 顶部临期横幅兜底]
    BAN --> L
    L --> EAT[S07 今天吃啥·按消化临期加权排序]
    L --> SKIP[不打算吃·S03 标记已用或删除]
    EAT --> DETAIL[S08 菜谱详情·用料与库存匹配标注]
    DETAIL -- 做了这道菜 --> CUT[按谱用量自动扣减]
    CUT -- 用量充足 --> OK[成功反馈·库存即时更新]
    CUT -- 用量不足 --> PART[不足置 0 并提示缺料]
```

### F3 主闭环总览(旅程级,四环循环)

```mermaid
flowchart LR
    A[采购回家] --> B[整拍录入 ≤10 秒]
    B --> C[日常查看·临期置顶]
    C --> D[临期提醒 3天 / 1天 / 当天]
    D --> E[今天吃啥·消化临期]
    E --> F[做了这道菜·一键核销]
    F --> C
    E -. 不想吃 .-> G[标记已用 / 删除]
    G --> C
```

### F4 订阅 IAP(P1 · D-013 上线后 1 月内;首发不出现)

```mermaid
flowchart TD
    A[S09 额度用尽或 S10 设置入口] --> B[S12 订阅介绍页]
    B --> C[选择档位·12 元每月或 98 元每年]
    C --> D[StoreKit 2 系统支付弹窗]
    D -- 成功 --> E[额度提升至 300 每月·成功反馈]
    D -- 取消 --> F[留在免费版·闭环仍完整]
    D -- 失败 --> G[失败提示加恢复购买入口]
```

- **三态反馈**:
  - 加载:识别上传显示进度动画 +「识别中…」(P95 ≤3 秒);列表首屏骨架屏;一切加载可取消。
  - 成功:入库 / 核销成功用 Toast(1.5 秒自动消失)+ 列表即时刷新,**不用打断式弹窗**。
  - 失败:内联错误 + 永远给两条出路(重试 / 降级手动录入);识别失败**绝不阻塞录入**(闭环红线,FR-04 兜底)。
