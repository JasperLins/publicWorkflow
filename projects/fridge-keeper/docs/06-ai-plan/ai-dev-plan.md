## 3. Token 消耗与产出比预估(三档)

> **单价假设**:编码代理模型 **GLM-4.6(智谱,输入 ¥5 / 输出 ¥25 每百万 token,查询日期 2026-08-17,来源 [智谱开放平台定价页](https://bigmodel.cn/pricing) 经检索汇总,中置信,下单前须复核;另存在折后价约 ¥4.3/¥15.8 与 GLM Coding Plan 包月口径,见待决策 Q2)**。代理 token 构成按 **输入:输出 = 85:15**(编码代理读多写少,与本框架台账子代理形态一致)→ **混合单价 0.85×5 + 0.15×25 = ¥8/百万 token**。识别 API 的运行成本(**¥0.0005/次**,tech-stack 已定)属运营成本,**不在本计划 token 口径内**,阶段 7 分列。

### 3.1 校准链条(台账实测 → 编码预估,必读)

| 阶段 | 台账 token | 产出量 | 实测消耗/产出比 |

**第二步·编码任务调整因子**(每条给出方向与量级依据):
1. **+ 构建自测反馈环**:代码须过编译/单测/原型一致性,重试与修复轮次多于文档(文档仅 QA 抽查)→ ×1.2~1.5;

3. **− 声明式代码密度**:SwiftUI/JSON 样板行生成效率高于论证型文档;
4. **分层计价**:数据内容行(食材库/菜谱 JSON)近乎模板化生成 → ×0.6。

**第三步·落位**:**代码与测试行 = 文档基线 1,650 × 1.33 ≈ 2,200 token/行(中性)**;乐 1,600(取反馈环 ×1.2、无检索下限约束),保 3,000(×1.8,覆盖联调返工与 A-017 迭代);**数据内容行 = ×0.6 → 960/1,320/1,800**。

**原型复现基准的使用方式**(`UI/` = 复现基准,13 文件):
