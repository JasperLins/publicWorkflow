## 6. UI 风格定义
- 设计关键词:高效、可信、清爽、工具感
- 参考风格:iOS 原生效率类 App(如计算器、备忘录)

## 7. 设计规范
- 色彩:主色 #2563EB(信任蓝);辅色 #0F172A(深灰蓝文字);语义色:成功 #16A34A / 警告 #D97706 / 错误 #DC2626;背景 #F8FAFC
- 字体:-apple-system / SF Pro;标题 20pt 粗体、正文 15pt、辅助 12pt 灰 #64748B
- 圆角:卡片 16px、按钮 12px;间距:页面边距 16px、卡片间 12px;阴影:卡片 0 2px 8px rgba(15,23,42,.08)
- 组件风格:主按钮满宽圆角蓝色白字;列表卡片式;输入分组卡片;空态用插画感 emoji + 文案
