# 项目画像(Project Profile)

> 状态:已确认(测试数据)
> 最近更新:2026-08-17

| 要素 | 内容 |
|---|---|
| 一句话概述 | 面向中小企业采购员的「采购快速决策计算器」App:输入供应商报价与参数,10 秒得出多维度比价与采购建议 |
| 目标用户 | 中小企业采购员、采购主管(次要) |
| 核心价值 | 把原本靠 Excel 手工比价 30 分钟的决策压缩到 10 秒,减少拍脑袋采购 |
| 本期做 | 报价录入、多供应商比价计算、历史记录、采购建议报告、本地数据存储(方向 A,见 D-004) |
| 本期不做 | 供应商管理系统、ERP 对接、多人协作、OCR/语音免录入(二期 C 方向)、微信小程序(二期复评)、云端同步(本地优先,见 D-008) |
| 关键假设 | 采购员愿意手动录入 ≥3 家报价;比价维度可标准化为价格/交期/账期/质量分;免费版无账号体系即可满足首期使用 |

## 决策摘要
- D-001:首期仅做移动端 App,不做 Web(2026-08-17)
- D-002:比价算法本期用加权评分制,不上 AI(2026-08-17)
- D-003:比价维度默认权重为 价格40%/交期25%/账期15%/质量20%(2026-08-17)
- D-004:首期方向 = A 先行、A+C 分期,OCR/语音免录入放二期(2026-08-17,阶段 1 复盘)
- D-005:目标人群主对象 = 采购员自用,功能围绕「快」(2026-08-17,阶段 1 复盘)
- D-006:商业模式 = 免费 + Pro 订阅,影响阶段 2/7(2026-08-17,阶段 1 复盘)
- D-007:平台边界 = 原生 App(Android + iOS 双端)(2026-08-17,阶段 1 复盘)
- D-008:数据策略 = 本地优先,OCR 上传前明示同意(2026-08-17,阶段 1 复盘)
